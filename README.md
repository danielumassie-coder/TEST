# Learn to Code - Beginner's Guide

Welcome to your coding journey! 🚀

This repository is designed to help you learn programming from scratch. Whether you've never written a line of code before or want to strengthen your fundamentals, you're in the right place.

## 📚 Learning Path

This guide covers multiple programming languages and concepts:

1. **Python Basics** - Start here! Python is beginner-friendly
2. **HTML & CSS** - Build your first web page
3. **JavaScript** - Add interactivity to websites
4. **Projects** - Apply what you've learned

## 🎯 Getting Started

### Option 1: Python (Recommended for Beginners)
Python is one of the easiest languages to learn and incredibly powerful.

1. Start with `python/01_hello_world.py`
2. Work through the tutorials in order
3. Try the exercises in `python/exercises/`

### Option 2: Web Development
Learn to build websites from scratch.

1. Start with `web/html_basics.html`
2. Move to `web/css_basics.css`
3. Then learn `web/javascript_basics.js`

## 📖 What You'll Learn

### Python Section
- Variables and data types
- Control flow (if/else, loops)
- Functions
- Lists and dictionaries
- File handling
- Object-oriented programming basics

### Web Development Section
- HTML structure and tags
- CSS styling and layouts
- JavaScript fundamentals
- DOM manipulation
- Building interactive web pages

## 🛠️ Setting Up Your Environment

### For Python:
1. Install Python from [python.org](https://python.org)
2. Open a terminal/command prompt
3. Run: `python filename.py`

### For Web Development:
1. You just need a web browser!
2. Open HTML files in your browser
3. Use browser developer tools (F12) to experiment

## 💡 Learning Tips

1. **Type the code yourself** - Don't just read it
2. **Experiment** - Change values and see what happens
3. **Make mistakes** - They're the best way to learn
4. **Build projects** - Apply what you learn
5. **Be patient** - Everyone starts somewhere
